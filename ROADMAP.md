# Harbor roadmap

Current release preparation: 0.5.7, regular Harbor identity and optional Proton browser protection. Earlier beta artifacts and profiles remain separate. See RELEASE-VERIFICATION.md, INSTALLER-VERIFICATION.md and LIVE-VERIFICATION.md for actual evidence.

Next milestones:

- Complete clean/offline installation and genuine prerequisite/restart validation on a spare Windows PC; broader Windows 11, display-scale and hardware checks.
- Verified update metadata and packages, clear update status, interrupted-download recovery and documented rollback.
- Long-session performance and website compatibility, accessibility, signed setup and broader recovery validation toward 1.0.
- Protocol/DNS/background-traffic testing before making broader VPN or privacy guarantees. Tor remains experimental; Proton remains optional with explicitly limited browser coverage.

The original installer/stability, memory, modular extension and privacy milestones continue through their delivered features and remaining checks. 1.0 remains a separate polished-release milestone.
