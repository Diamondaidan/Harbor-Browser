Palette: midnight navy, sea-glass teal, warm ivory and copper/amber. Keep the icon upright, preserve its aspect ratio, and leave space around it. The lighthouse is the main symbol; the copper beam provides the small accent. Use the ICO for Windows rather than renaming a PNG.

These are raster assets. The selected icon is generated artwork, not a hand-drawn vector master. The other concepts remain an exploration sheet, not separate production logos.

Created with the built-in image-generation tool. Exact prompts and reference roles are recorded in PROMPTS.md. Image generation was followed by standard Windows ICO format conversion for the selected mark.
